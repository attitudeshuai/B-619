# 测试指南 (Testing Guide)

## 1. 自动化测试

目前项目主要依赖 API 接口测试和 Docker 部署验证。

### 健康检查
验证后端服务是否正常存活：
```bash
curl http://localhost:8080/api/auth/health
# 预期响应: {"code":200, "data": "服务运行正常", ...}
```

## 2. 手动功能验证 (Manual Verification Checklist)

### 2.1 用户认证
- [ ] 访问 `http://localhost:3000` 自动跳转登录页
- [ ] 输入错误密码，提示错误信息
- [ ] 输入账号 `admin` / 密码 `admin123`，登录成功跳转至仪表盘

### 2.2 仪表盘
- [ ] 检查顶部欢迎语包含当前登录用户的昵称
- [ ] 检查统计卡片数据是否加载（客房总数、入住率等）
- [ ] 检查快捷操作按钮是否能导航至对应模块

### 2.3 客房管理
- [ ] 进入客房管理页面，列表正常加载
- [ ] 点击"新增客房"，填写表单提交，列表刷新出现新记录
- [ ] 尝试修改客房状态（如空闲 -> 维护中）

### 2.4 预订与入住流程
1. **新建预订**: 在预订管理中，选择客房和会员，设定日期，提交预订。
2. **确认入住**: 找到该预订记录，点击"确认入住"，验证客房状态变为"已入住"。
3. **退房结算**: 在入住登记中，找到该记录，点击"退房"，系统计算费用并更新状态为"已退房"。

### 2.5 报表统计
- [ ] 进入财务报表页面
- [ ] 切换按周/按月统计，折线图应动态更新
- [ ] 验证数据趋势是否符合预期
