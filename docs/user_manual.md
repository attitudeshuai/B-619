# 用户手册 (User Manual)

欢迎使用酒店运营管理系统。本手册将指导您完成常见的日常操作。

## 1. 登录系统

1. 打开浏览器访问系统地址（默认：http://localhost:3000）。
2. 在登录界面输入用户名和密码。
   * **默认管理员**: `admin`
   * **默认密码**: `admin123`
3. 点击"登录"按钮进入系统。

## 2. 仪表盘

登录后首先看到的是仪表盘，这里展示了酒店的今日概况：
* **实时入住率**: 仪表盘顶部的大型进度条。
* **关键指标**: 客房总数、今日订单、会员总数等。
* **快捷入口**: 快速跳转到常用功能的按钮区域。

## 3. 核心功能操作

### 3.1 客房管理 (Room Management)
用于管理酒店的所有物理房间。
* **查看**: 浏览所有房间的状态、价格、类型。
* **新增**: 点击右上角按钮添加新房间，需填写房间号、房型、价格和楼层。
* **修改**: 对已有房间信息进行编辑，或手动更改房间状态（如设置为"维护中"）。

### 3.2 预订管理 (Booking Management)
处理客人的预订请求。
* **新建预订**: 选择客人（会员）、房间、入住和退房日期。系统会自动校验房间是否空闲。
* **取消预订**: 在客人未入住前废弃预订，释放房源。
* **转入住**: 预订客人到达后，一键将预订信息转为正式入住登记。

### 3.3 入住登记 (Front Desk)
前台接待的核心功能。
* **办理入住**: 对于无预订的散客，直接在此处录入信息办理入住。
* **退房结算**: 客人离开时，点击"退房"，系统将结束计费周期并释放房间状态为"空闲"（需安排保洁）。

### 3.4 会员管理 (Membership)
* **注册会员**: 录入客人姓名、手机号等信息注册。
* **充值**: 为会员账户充值余额，系统会自动记录。
* **积分**: 消费自动累计积分，支持手动调整。

### 3.5 财务报表 (Reports)
* **收入统计**: 查看每日、每周或每月的营收趋势图。
* **经营分析**: 查看入住率变化曲线。
* **会员消费**: 查看高价值客户排行。

## 4. 系统设置

* **管理员管理**: 添加新的系统操作员或修改密码。
* **参数配置**: 修改酒店名称、默认配置项等（规划中）。

**提示**: 如遇系统异常，请记录错误提示并联系技术支持（或参考测试指南进行排查）。
